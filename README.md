# Scripting

給 [Scripting](https://scripting.fun)（iOS）使用的腳本集合。

## 腳本

| 名稱 | 簡介 | 導入連結 |
| --- | --- | --- |
| Vesper | 支援 Venera 與 Aidoku 來源的漫畫閱讀器，內建書架、搜尋、離線閱讀與 ACNet 圖片超解析。 | [導入](https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fraw.githubusercontent.com%2FYswag%2FScripting%2Frefs%2Fheads%2Fdist%2FVesper.zip%22%5D) |
| SideInstaller | 以 Apple ID 登入，直接在 iPhone 上安裝 SideStore；內建 Anisette 與 JIT 相關支援。 | [導入](https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fraw.githubusercontent.com%2FYswag%2FScripting%2Frefs%2Fheads%2Fdist%2FSideInstaller.zip%22%5D) |
